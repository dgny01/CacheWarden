# Security Policy

CacheWarden Milestone 1 is a local experiment and is not designed for direct
Internet exposure or production use.

Report a suspected vulnerability through a private GitHub security advisory
after the public repository is created. Do not open a public issue containing
exploit details, credentials, personal data, or sensitive infrastructure
information.

The aggressor is intentionally resource intensive but bounded. A report about
unexpectedly unbounded CPU or memory use is considered a safety issue.
